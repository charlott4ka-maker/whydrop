# Ago

Сколько прошло с тех пор, как ты делала то, что делаешь редко. Поменяла линзы,
постирала шторы, была у стоматолога, звонила бабушке. Одна строка, крупная
цифра, тап — и счётчик обнулился.

Это не трекер привычек: приложение ничего не требует и не ругает. Оно отвечает
на вопрос, который и так возникает сам, и тем снимает тревогу, а не добавляет.

```
src/app/(tabs)/   index — список, feed — лента, settings — настройки и итоги
src/app/item/     страница пункта, открывается поверх вкладок
src/lib/items.ts  модель, история отметок, подсмотренный интервал, прогноз
src/lib/time.ts   счёт дней, склонения, человеческие подписи
src/components    дизайн-система, общая с whydrop
```

## Как устроено

- **История, а не одна дата.** Каждая отметка остаётся. По трём отметкам
  приложение считает медиану промежутков и само понимает, как часто ты это
  делаешь: срок можно не задавать вообще. Медиана, а не среднее, чтобы один
  пропущенный год не перечёркивал картину.
- **Дни по календарю.** Отметила вчера в одиннадцать вечера, смотришь утром —
  это «вчера», а не «сегодня».
- **Порядок списка.** Сверху просроченное сильнее всего, дальше просто давнее.
  «Ещё ни разу» считается бесконечно давним: это незакрытый вопрос.
- **Отметка задним числом.** «Я меняла линзы в прошлый вторник» — обычный
  случай, а не исключение.
- **Поиск и фильтр появляются сами**, когда список перерастает восемь пунктов.
  На пяти они были бы шумом. Поиск смотрит и в заметки: «Aquaphor» человек
  помнит лучше, чем «фильтр».
- **Прогноз.** Срок известен, значит смотреть только назад — половина пользы:
  на странице пункта стоит «следующий раз около 12 декабря».
- **Стекло.** Таб-бар системный, на iOS 26 он сам приходит с Liquid Glass.
  Контент проезжает под ним, а под всеми экранами лежит общий слой со светом
  (`components/Glow.tsx`): на ровном чёрном стекло превращается в серый.

- **Копия как текст.** «Сохранить копию» отдаёт весь список обычным текстом
  через системное окно: в заметки, в чат, куда угодно. «Восстановить» принимает
  его вставкой. Файлов и облака нет, и пока это единственный способ не потерять
  историю вместе с телефоном.

Данные лежат только на устройстве: ни сервера, ни входа, ни одного сетевого
запроса.

## Виджет

Лежит в `targets/widget/`: `index.swift` рисует, `expo-target.config.js`
объявляет цель. Приложение кладёт в общий контейнер только даты и сроки
(`src/lib/widget.ts`), а дни виджет считает сам — он обновляется по своему
таймлайну, и готовое число замёрзло бы на дне последнего запуска.

Уведомлений в приложении нет и не будет: «пора менять линзы» в пуше это ровно
то нытьё, против которого оно сделано. Виджет решает ту же задачу правильно —
человек сам смотрит на растущее число.

### Что нужно сделать руками один раз

```bash
cd ago
npm install                       # ставит @bacons/apple-targets
rm src/types/apple-targets.d.ts   # у пакета свои типы, заглушка больше не нужна
npx expo prebuild --clean         # создаёт ios/ с целью виджета
npm run build:dev                 # или npx expo run:ios
```

Перед этим в `app.json` заменить `appleTeamId` на свой Team ID: он виден на
developer.apple.com в разделе Membership. Группа приложений
`group.app.ago.ios` объявлена и у приложения, и у виджета — её надо завести
в Certificates, Identifiers & Profiles, иначе сборка не подпишется.

Добавление цели меняет провижининг, поэтому первая сборка в EAS должна быть
интерактивной, чтобы профиль пересоздался.
