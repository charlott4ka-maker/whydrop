# Давно

Сколько прошло с тех пор, как ты делала то, что делаешь редко. Поменяла линзы,
постирала шторы, была у стоматолога, звонила бабушке. Одна строка, крупная
цифра, тап — и счётчик обнулился.

Приложение не просит ничего отслеживать и ни к чему не принуждает: это не
трекер привычек, а ответ на вопрос, который и так возникает сам.

```
src/app/      единственный экран и шит редактирования
src/lib/      items.ts — модель и хранилище, time.ts — счёт дней
src/components, src/theme — дизайн-система, общая с whydrop
```

Данные лежат только на устройстве: ни сервера, ни входа, ни чужих API.

## Запустить

```bash
npm install
npx expo start
```

## Проверки

```bash
npm run typecheck
npm test
```
